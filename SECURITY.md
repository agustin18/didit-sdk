# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a paramount concern for cryptographic and identity verification libraries.

If you believe you have found a security vulnerability in `didit-sdk`:

1. **Do not** report the issue in public GitHub issues or discussions.
2. Email details of the vulnerability privately to **agustinsaiz02@gmail.com**.
3. Please include:
   - A description of the issue and potential impact.
   - Minimal reproducible proof of concept or code sample.
   - Suggested mitigations or patches if known.

### Response Timeline

- **Initial acknowledgment**: within 24 hours.
- **Assessment and triage**: within 72 hours.
- **Fix release**: coordinated via patch release tag.
